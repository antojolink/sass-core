# AntojoLink (`sass-core`)

Backend SaaS Multi-Tenant de **AntojoLink** para la gestión y publicación de menús digitales mediante códigos QR.

## Documentación

Consulta la arquitectura, diagramas, endpoints, ambientes y plan de trabajo en la [Wiki del repositorio](https://github.com/antojolink/sass-core/wiki).

## Repositorios de la organización

- `antojolink/sass-core` — Backend (API Express, Knex, PostgreSQL, Docker y pipeline)
- `antojolink/admin-web` — Panel de administración (React + Vite)
- `antojolink/menu-web` — Menú público móvil (Astro)
- `antojolink/infra` — Infraestructura como código (Terraform en AWS `us-east-2`)
